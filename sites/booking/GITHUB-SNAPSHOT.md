## Запуск

Требуется Node.js 24.15+ и менеджер pnpm. Из этой папки:

```sh
npm run install:ci
npm run dev
```

Инструкции исходного проекта находятся в `README.md`. Локальные секреты задавайте вне Git. Для проектов с D1 примените файлы `drizzle/*.sql` к локальной БД; рабочую БД сюда не копируйте. Сборка: `npm run build`.

Проекты Sites используют Vinext/Cloudflare Workers и D1; наличие кода в GitHub не создаёт и не настраивает эти сервисы. Демо-вход, если он предусмотрен прототипом, не подходит для боевой эксплуатации. Почта, Telegram и облачное резервирование требуют отдельных секретов и настройки; доставка не подтверждена этой копией.
