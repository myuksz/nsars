# Подключение уведомлений и резерва

Проверочная версия хранит записи в D1. Перенос на Beget пока не выполнялся. Ни один внешний канал сейчас не подключён: значения среды пусты.

## Уведомления

Нужны существующий Telegram-бот, проверенный chat_id Наталии и серверная отправка почты. Адрес получателя фиксирован: notifications@example.invalid. Секреты вводятся через защищённые настройки окружения, а не в переписку и не в репозиторий.

BOOKING_NOTIFY_ENDPOINT — HTTPS-обработчик в имеющейся инфраструктуре ботов/почты. BOOKING_NOTIFY_TOKEN — его серверный Bearer-токен. BOOKING_TELEGRAM_CHAT_ID — проверенный чат. Дополнительный сервер не требуется: при переносе обработчик может работать на имеющемся хостинге. Исходящие raw SMTP/TCP на GPT Sites не поддерживаются; нужен HTTPS-канал.

POST содержит event=booking.requested, notification_id, recipient_email, recipient_telegram_chat_id, channels, booking и text. Проверять Bearer-токен, сохранять idempotency по заголовку Idempotency-Key отдельно для каждого канала. Возвращать email.status/telegram.status=sent только после подтверждения провайдером. HTTP 200 без этих полей не означает отправку. Частичный успех повторяет только неподтверждённый канал. Ошибка уведомления не отменяет заявку. Очередь хранится в D1; повтор доступен владельцу. Автономный плановый обработчик сейчас не подключён.

## Яндекс Диск

Доступ осуществляется официальным REST API с OAuth-токеном YANDEX_DISK_OAUTH_TOKEN. Папка по прямой команде Сергея — disk:/Дублирование с сайтов. YANDEX_BACKUP_FOLDER задаёт этот путь. Право cloud_api:disk.app_folder для такой папки вне каталога приложения недостаточно; официальный OAuth должен разрешать чтение и запись файлов Диска. Разрешение подтверждает владелец в Яндексе. Код работает только с заданной папкой. Токен на GPT задаётся нативным инструментом Sites как secret; после изменения нужна публикация новой версии. На Beget — только серверное окружение.

Папка disk:/Дублирование с сайтов содержит «Запись на съёмки.xlsx» , «Свободные даты.xlsx» (без контактов/заметок/частных статусов) и датированные копии рабочего журнала. В книге листы «Календарь», «Заявки», «Сведения»: все исходные даты, текущие статусы, контакты, заметки и история заявок. Исходный Excel не перезаписывается. Резерв обновляется после заявки/правки и повторно при открытом управлении. Не подключён независимый таймер; после сбоя провайдера повтор происходит при следующем обращении к управлению или кнопкой «Обновить копию». Статус успешен только после сверки SHA-256 файла на Диске. Пока OAuth не подключён, работает защищённое скачивание Excel владельцем.

Одновременно выполняется один процесс копирования. Версия резерва фиксируется в одной транзакции чтения. Если при проверке SHA-256 обнаружено ручное изменение общего Excel, обновление останавливается; исходная ручная версия не заменяется. Проверка перед записью не является блокировкой редактора Яндекса: при активном ручном редактировании сначала прекратить запись с сайта. Полный runtime-тест API, редактирования Яндексом, доступа к папке приложения и сохранения постоянной ссылки при замене файла выполнить после OAuth-подключения.

При сбое Beget Наталия ведёт запись в таблице. После восстановления сначала сверяет ручные изменения и переносит их на сайт. Снять manual_hold и обновить remote_sha можно только после явного разбора конфликта; публичной кнопки сброса нет. Двусторонняя синхронизация не заявлена. Публичный просмотр/редактирование таблицы пока не включались: перед выдачей клиентам определить доступ и проверить конкретную ссылку; резерв содержит контакты и заметки, поэтому весь резерв нельзя публиковать клиентам. Для клиентов формируется отдельный файл «Свободные даты.xlsx» только с датами и доступностью.

## Перенос на Beget

OAuth-приложение Яндекса и выбранную папку можно использовать для того же проекта после переноса. Учесть реальные ограничения и срок OAuth-токена. Секрет передаётся в защищённые серверные настройки, не в исходники/архив. HTTP-операции Яндекса повторно не проектируются; Cloudflare env/D1/waitUntil заменяются адаптерами окружения, БД и фоновых задач Beget. Не заявлять перенос завершённым без отдельного сквозного теста после переноса.
