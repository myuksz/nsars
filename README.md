## Что сохранено

Исходный код, зависимости с lock-файлами, миграции и схемы БД, тесты, технические инструкции. Рабочая база CMS, заявки и контакты клиентов, заметки календаря, личные фотографии, видео, `.env`, пароли, токены и служебные кэши исключены. В календарном seed удалены действующие записи. Часть медиа и соответствующий тестовый photo fixture исключены; восстановление оригинального вида потребует частного хранилища разрешённых медиа. Подробности: [SNAPSHOT-REPORT.json](SNAPSHOT-REPORT.json).

Это **снимки исходников, а не полные аварийные резервные копии данных**. Работа сайта и почтовых уведомлений одной копией кода не обеспечивается. Прототипы с демонстрационным входом нельзя развёртывать как защищённую рабочую систему без настройки доступа.

## Запуск

В каждой папке есть исходный `README.md`; в восстановленных Sites — `GITHUB-SNAPSHOT.md` с происхождением и ограничениями. Для Sites требуется Node.js 24.15+ и pnpm. Перейдите в выбранную папку, выполните `npm run install:ci`, затем `npm run dev`. Приложения используют Vinext, Workers и D1; миграции находятся в `drizzle`. `.env.example`, если присутствует, содержит только имена параметров и пустые значения. Секреты и данные настраиваются отдельно, за пределами Git.

У Beget другой runtime — Node.js и встроенный SQLite. Его неполный срез пока не запускается; список недостающих файлов находится в `sites/nsars-beget-recovered/RECOVERY-STATUS.json`. Не объединяйте старую версию Sites с этим срезом как будто это подтверждённая текущая сборка.

## Обновление и проверка

После каждой дальнейшей правки сайта сохраняйте соответствующие исходники в этом репозитории, обновляйте `SITES.json`, выполняйте проверки проекта и фиксируйте commit. Проверяйте содержимое удалённого GitHub перед сообщением о сохранении. Для нового сайта добавляйте отдельную папку и инструкцию запуска. Непроверенные версии обозначайте явно.

`python3 tools/check_snapshot.py` проверяет состав и известные опасные типы файлов; `SHA256SUMS` фиксирует байты снимка. Это вспомогательные проверки, а не гарантия обнаружения любого секрета. В этом переносе выполнены проверки целостности, структур и доступные тесты; полная сборка/браузерная проверка всех сайтов не выполнялись.

Автоматическая синхронизация с действующими хостингами и автоматическое развёртывание **не подключены**. Действующие сайты, DNS и хостинг этой операцией не изменялись.
