# NS-ARS PRO

Предрелизная сборка сайта «Дом детской фотографии» для будущего точного origin
`https://ns-ars.ru`.

## Текущий статус

- девять публичных маршрутов и собственная страница 404;
- русскоязычный CMS: черновик, точный предпросмотр, неизменяемая ревизия,
  публикация и откат;
- D1 хранит страницы, ревизии, активные указатели, медиаметаданные и журнал действий;
- R2 хранит оригиналы JPG, PNG и WebP; галереи, смешанные слайдеры и макеты с
  четырёхточечными фотозонами настраиваются в русскоязычном редакторе;
- SIWC устанавливает личность администратора, серверный allowlist выдаёт право
  изменения;
- текущий текст собран заново по подтверждённому бизнес-базису; детские фото,
  цены, контакты, отзывы и неподтверждённые условия не публикуются;
- индексация, контактная отправка и публичное размещение пока выключены.

Статус осей не объединяется: `PRODUCED`, `QA_PASS`, `APPROVED` и
`VERIFIED_RUNTIME` фиксируются отдельно в `docs/governance/`.

## Стек и данные

- Next.js 16 / React 19 / Vinext;
- Cloudflare Worker;
- D1 binding `DB`;
- R2 binding `BUCKET` для приватных оригиналов медиатеки;
- Drizzle-схема и SQL-миграция находятся в `db/` и `drizzle/`;
- при первом обращении сервер идемпотентно создаёт схему и девять стартовых
  R1-ревизий, не перезаписывая существующие записи.

## Локальная работа

Требуется Node.js `>=22.13.0`.

```bash
npm run dev
npm run lint
npm test
```

`npm test` выполняет production build и проверяет контракты, медиаблоки, маршруты, защитные
заголовки, robots/sitemap, запрет ранней индексации, закрытые admin API и все
внутренние ссылки.

Пример переменных находится в `.env.example`:

- `NSARS_ADMIN_EMAIL`, `NSARS_ADMIN_PASSWORD_SALT_HEX` и
  `NSARS_ADMIN_PASSWORD_HASH_HEX` — собственная учётная запись конструктора;
  соль и хеш хранятся только как секреты среды, пароль в конфигурацию не входит.

## Предохранители релиза

- допустимый будущий production origin — только `https://ns-ars.ru`;
- ошибочно направленные запросы московской сборки к защищённому Wfolio-домену
  Пензы `ns-ars-production.ru` отклоняются кодом 421; сам домен и Wfolio не
  входят в контур этой сборки и не изменяются;
- все административные маршруты, включая локальный preview, требуют собственную
  защищённую серверную сессию и same-origin; вход ограничен блокировкой перебора,
  а внешние служебные заголовки очищаются на границе;
- выпуск или перенос запрещён без проверки, что прежний логин и пароль владельца
  продолжают работать без изменения;
- произвольный HTML/CSS/JS и внешние URL запрещены контрактом данных;
- файл не может попасть в публичную ревизию без одновременно подтверждённых
  прав, статуса READY и проверенной независимой копии;
- `/api/brief` возвращает 503 и не читает тело запроса;
- CSP запрещает встраивание; исключение для responsive QA действует только в
  локальном preview;
- все ответы предрелизной сборки имеют `no-store` и `noindex`;
- закрытый noindex-checkpoint разрешён владельцем; DNS, custom domain и открытая
  публикация остаются отдельными этапами после проверки checkpoint.

Актуальная приемка и инструкция этапа размещения находятся в `docs/release/`.
