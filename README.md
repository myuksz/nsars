## Состав и конфиденциальность

Сохранены код, схемы и миграции, lock-файл исторического проекта, тесты и инструкции. Рабочие базы, заказы, клиентские контакты, фотографии, видео, `.env`, токены, пароли, учётные записи и кэши не включены. Найденный архив Beget сам по себе этих данных не содержит. В очищенной копии заменён контактный телефон и убраны прямые личные ссылки. Подробности: [SNAPSHOT-REPORT.json](SNAPSHOT-REPORT.json). История исходных Git-репозиториев не переносилась.

Это сохранение исходников, а не полная аварийная копия рабочих данных. Наличие кода не подтверждает доставку почты, работу авторизации или уведомлений.

## Запуск

Исторический Sites: Node.js 24.15+, команды из его README и GITHUB-SNAPSHOT.md. Из папки `sites/nsars-historical`: `npm run install:ci`, затем `npm run dev`; сборка — `npm run build`. Требуются Vinext/Cloudflare Workers и отдельная D1 с миграциями из `drizzle`. Приватные значения настраиваются вне Git.

Beget: Node.js 24.15+, встроенный SQLite, вход `server.cjs`. Пока не восстановлены файлы из RECOVERY-STATUS.json, команду `node server.cjs` нельзя считать рабочей. Для реального восстановления также нужны закрытые данные CMS, медиа и конфигурация хостинга.

## Проверки и дальнейшая работа

Проверены совпадение исторического source commit с последней сохранённой версией, относительные импорты исторического проекта, синтаксис найденного Beget-кода и 17 тестов контрактов CMS. Полные сборки, браузерные тесты и действующий сайт этой операцией не проверялись.

`python3 tools/check_snapshot.py` проверяет состав, JSON и известные опасные типы файлов. SHA256SUMS фиксирует байты сохранённой копии. Это вспомогательная проверка, а не гарантия обнаружения любого секрета.

Все дальнейшие разрешённые правки ns-ars.ru сохраняйте здесь отдельными commit с актуальным SITES.json и инструкцией запуска. Проверяйте удалённый commit перед заявлением о сохранении. Сохранение в GitHub не означает публикацию сайта. Автоматическая синхронизация и deployment не подключены; сайт, DNS и хостинг не менялись.

## Страница бронирования

Исходники: `sites/booking`, инструкция: `sites/booking/GITHUB-SNAPSHOT.md`. Прототип использует Workers/D1; действующие записи и внутренние заметки из seed удалены. Публичный код не является копией клиентских данных. Восстановление календаря требует отдельного закрытого импорта. Почта, Telegram, Яндекс.Диск и боевой вход требуют закрытых настроек; их работоспособность этим сохранением не подтверждена.

Перейдите в `sites/booking`, выполните `npm run install:ci`, затем `npm run dev`. Полная сборка и браузерная проверка прототипа в этой операции не проводились. Другие проекты в репозиторий не добавлены.
