## Архитектура и последующий запуск

Node.js 24.15+, встроенный `node:sqlite`. Вход — `server.cjs`, код сервера — `runtime/server.mjs`; `NSARS_DATA_DIR` задаёт частный каталог вне Git. После восстановления недостающих файлов, приватной БД, медиа и серверной конфигурации запуск производится из этой папки:

```sh
node server.cjs
```

Сейчас эту команду нельзя считать рабочей: отсутствуют необходимые исходные JSON/MJS. Сайт и хостинг при создании этой копии не менялись. Автоматическое развёртывание из GitHub не подключено.
